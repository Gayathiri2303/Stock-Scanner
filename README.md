# 📈 Stock Scanner

An AI-powered stock analysis and screening platform that helps users discover, analyze, compare, and track stocks using market data, AI-based insights, watchlists, seasonal analysis, and investment recommendations.

## 🌐 Live Demo

**Live Application:** https://gayathiriportfolio.xyz/stockscanner/

**GitHub Repository:** https://github.com/Gayathiri2303/Stock-Scanner

---

## 📌 Project Overview

Stock Scanner is a web-based stock market analysis platform designed to help users quickly identify and evaluate stocks.

The platform provides:

* Stock market screening and filtering
* AI-based stock analysis
* Top stock picks
* Personal watchlist management
* Seasonal stock analysis
* Investment recommendations
* Market overview and sector analysis
* Stock price comparison
* Automatic market data updates
* USD/INR conversion for investment calculations
* Portfolio and withdrawal calculations

---

## ✨ Key Features

### 📊 Stock Market Scanner

The application allows users to browse and filter stocks based on different criteria such as:

* Stock price
* Sector
* Market performance
* Price changes
* Other available stock metrics

Users can quickly identify stocks that match their selected conditions.

### 🤖 AI Stock Analysis

The platform provides AI-assisted analysis to help users understand stock performance and identify potentially interesting stocks based on available market data.

### 🏆 Top 3 Stock Picks

Displays the top three selected stocks based on the application's analysis and ranking system.

### ⭐ Watchlist

Users can maintain a personal watchlist to keep track of selected stocks and monitor them easily.

### 📅 Seasonal Stock Analysis

The application provides stock recommendations based on seasonal performance and selected periods.

### 💰 Investment Recommendation

The platform includes an investment calculator that provides recommendations for a **₹10,000 investment**, including:

* Recommended stock
* USD/INR exchange rate
* Final investment amount
* Allocation percentage
* Number of shares
* Estimated withdrawal amount

### 📈 Market Overview

Provides an overview of the stock market through:

* Sector-wise price analysis
* Top stock changes
* Stock filtering
* Market performance data

### 🔄 Automatic Updates

Market information is automatically refreshed at regular intervals to keep the dashboard updated with the latest available data.

### 🌙 Dark Mode

The dashboard includes a dark mode option for improved viewing experience.

### 🔐 User Authentication

The application includes a login system to provide authenticated access to the stock analysis dashboard.
